# DayVault 同步工具（Windows）

把 DayVault 设备上录制的音频自动导出到电脑。设备插上 USB 后，本工具自动识别、校准时间，
并把设备上尚未导出的录音下载到电脑的同步文件夹中，全程无需手动输入命令。

## 功能

- **自动检测**：监听 USB 串口，识别 DayVault 设备（VID `0483` / PID `5740`），插入后自动开始同步。
- **时间同步**：每次同步都会把设备的 RTC 时间与当前电脑时间对齐（含本地时区偏移）。
- **自动下载**：对比设备上的录音列表与已下载记录，仅下载新增或大小变化的文件，下载到
  `<同步文件夹>\<设备序列号>\`。
- **断点续传式下载**：下载失败自动重试（最多 3 次），临时文件以 `.part` 结尾，完成后改名，
  异常中断不会残留半截文件。
- **托盘驻留**：关闭窗口只是最小化到系统托盘，后台继续监测设备；从托盘可重新打开主界面或退出。

## 安装 / 构建

源码运行需要 Python 3.10+（推荐 3.12+），开发环境为 3.14：

```bash
cd tools/dayvault_sync
pip install -r requirements.txt
python main.py
```

打包为单个 EXE（需已安装 PyInstaller）：

```bat
cd tools/dayvault_sync
build_exe.bat
```

产物位于 `dist\DayVaultSync.exe`，是一个免安装的单文件程序。

## 运行

双击 `DayVaultSync.exe` 即可。启动后窗口显示：

- 顶部下拉框列出检测到的设备，旁边是「立即同步」按钮。
- 表格列出当前设备上的录音文件：文件名、大小、时间、状态（已下载 / 未下载 / 下载中 / 下载失败）。
- 底部显示同步文件夹路径，可用「选择…」按钮修改。

## 配置 / 状态 / 日志位置

所有文件存放在 `%APPDATA%\DayVault\`：

| 路径 | 内容 |
| --- | --- |
| `%APPDATA%\DayVault\config.json` | 配置：`sync_folder`（同步文件夹）、`poll_interval_ms`（检测间隔，默认 1500）、`autostart` |
| `%APPDATA%\DayVault\state\<序列号>.json` | 每台设备各自的已下载记录：`文件名 -> 大小` |
| `%APPDATA%\DayVault\logs\app.log` | 运行日志，最大 512 KB、滚动保留 2 份 |

## 自动行为

- 设备插入后自动开始同步（无需点击）。
- 每次同步：校准时钟与时区 → 读取设备文件列表 → 对比已下载记录 → 下载未同步文件。
- 下载目录：`<同步文件夹>\<设备序列号>\`，与设备序列号一一对应。
- 状态表基于 `state\<序列号>.json` 判断：文件已存在且大小一致标记为「已下载」，否则「未下载」。

## 托盘

- 关闭窗口：默认最小化到托盘并继续监测，不退出程序。
- 左键单击托盘图标：重新打开主界面。
- 右键托盘图标：菜单含「打开主界面」和「退出」。

## 常见问题（Troubleshooting）

- **串口被占用（COM busy）**：如果另一个程序（如串口助手、dfu-util）正在占用设备串口，
  同步会失败并显示错误。关闭占用程序后点「立即同步」重试。
- **识别不到设备**：确认设备已通过 USB-C 连接，且系统能枚举到 `0483:5740` 设备（可用
  `pnputil /enum-devices` 或设备管理器确认）。若设备处于 DFU 模式则不会出现在列表中，
  需要复位设备进入正常模式。
- **电池电量低的设备**：设备低电时会进入休眠，可能暂时无法枚举，同步会失败。给设备充电后
  再次插入即可。
- **日志排查**：所有同步细节都记录在 `%APPDATA%\DayVault\logs\app.log`，排查问题先看这里。

## 开发

- 包结构：`dayvault/`（`proto` 协议解析、`dio` 串口检测与 DL2 下载、`store` 配置/状态/日志、
  `engine` 同步编排、`app` PySide6 界面），入口为 `main.py`。
- 测试：`cd tools/dayvault_sync && python -m pytest`。
